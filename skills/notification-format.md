# Формат уведомления

Одно уведомление на весь прогон, все важные пункты вместе:

```
Важное из «<название группы>»:
- <предмет>: <что сделать>, срок <дата и время>
- <изменение в расписании: день, пара, что поменялось>
```

Правила:
1. Каждый пункт одной строкой, сначала суть, потом срок.
2. Даты писать как в сообщении, ничего не додумывать. Если срок не указан, так и написать: «срок не указан».
3. Без болтовни и без пунктов, которые не важны по навыку important-messages.
4. В message_ids передать id всех сообщений, на которых основаны пункты.
5. Если важного нет, уведомление не отправлять.
